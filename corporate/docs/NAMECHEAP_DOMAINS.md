# BioScience Global: two Namecheap domain configuration
Canonical domain: https://www.biosciglobal.ca
Secondary domain: https://www.biosciglobal.net (301 redirect to matching canonical .ca URL if supported by redirect provider)
Current Higgsfield URL: https://bioscience-global-ferravitin.higgsfield.app
This website is deployed as a server-rendered TanStack Start app on Higgsfield's Cloudflare Worker. The Higgsfield tools currently available do not provide custom-domain onboarding, DNS editing or certificate issuance. DO NOT add arbitrary CNAME values or point public domains at the higgsfield.app URL without the host confirming custom hostnames.
## Path A: Host on AWS Amplify
1. Deploy this repository to an Amplify Hosting project supporting the site's server-side routes (/api/lead and /api/blog); adapt the worker build/runtime to the supported Amplify SSR deployment method or migrate endpoints to supported server functions. Confirm successful preview and full-page route refreshes.
2. In AWS Amplify > Hosting > Custom domains add biosciglobal.ca and biosciglobal.net. Designate www.biosciglobal.ca as primary and arrange www.biosciglobal.net as a 301 redirect. Configure root/apex redirects only after checking current DNS and provider support.
3. Copy the exact per-domain CNAME / validation and apex records Amplify gives you; values are account and deployment specific and cannot be guessed. Setup HTTPS certificates, verify both domains' statuses.
4. Log into Namecheap > Domain List > Manage > Advanced DNS (or the current authoritative DNS provider if Namecheap BasicDNS is not in use). Export/screenshot existing records first. Add only the relevant site A/ALIAS/CNAME and validation records generated by Amplify; update or delete only conflicting WEBSITE records. Do not change MX, SPF, DKIM, DMARC, autodiscover or other mail service TXT/CNAME records.
5. Once TLS and domain validation succeed, verify: http->https, www and apex redirect, .net -> .ca canonical, sitemap canonical URLs, all pages and blog/enquiry endpoints, existing email inbound/outbound.
## Path B: Keep Higgsfield hosting
Custom host mapping requires Higgsfield operator/support confirmation and per-domain hostname/TLS instructions. Ask Higgsfield for support of both custom hostnames www.biosciglobal.ca and www.biosciglobal.net and its exact DNS verification records. Do not assume that CNAME to *.higgsfield.app works.
## Preserve existing email
Both domains may carry business mail. Before any DNS edits export ALL existing DNS and confirm that MX, SPF, DKIM, DMARC, MTA-STS, and other mail records are unchanged. Never change nameservers merely to publish the website unless you can migrate all records.
## Google workflow
Configure GOOGLE_SHEETS_WEBHOOK_URL, GOOGLE_BLOG_FEED_URL and GOOGLE_SHEETS_SHARED_SECRET securely on the production server. Validate Google lead row and notification before public go-live.
